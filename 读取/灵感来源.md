# 灵感来源 · 这个包借了谁的骨

> **不是从零想出来的。** 下面这几个开源项目解决的是同一件事的不同变体：
> **把混乱的、丢失了原始意图的东西，重建成一份干净、可读、还能验证的结构。**
>
> 抄的是**思路**，不是代码。代码一行没复制 —— 而且真抄了反而学不像，因为它们的领域不是记忆。
> 但骨是从这些地方来的，写明出处。

---

## 一览

| 项目 | 它干什么 | 我们借了什么 | 来源 |
|---|---|---|---|
| **retcon** | 把烂 git 分支历史重构成干净的逻辑提交 | spec 驱动 · 确定性/LLM 边界 · 自愈循环 · stuck 必须人写 resolved | https://github.com/nikomatsakis/retcon |
| **OpenRewrite** | 大规模源码自动重构（Java 起家） | 无损语义树 · 最小侵入变换 · recipe 聚合 · 改完看 diff 再提交 | https://github.com/openrewrite/rewrite |
| **Revitalize** | 没有源码，从反汇编重建出可维护源码树 | 「理解 = 重建」· 从碎片倒推意图 · 残料也能立骨架 | https://github.com/jkoppel/Revitalize |
| **SnapBack** | 独立于 git 的项目快照，CAS 去重 | 内容寻址 · 快照不复制 · manifest 即索引 | https://github.com/SpaceCypher/snapback |

## retcon（Niko Matsakis，Rust，Apache-2.0）

**一句话**：*"Because you knew what you were doing the whole time."*

**借的**：

1. **确定性的事必须确定性地做。** 解析 spec、建分支、算 diff、跑构建测试、记状态 → 死代码。提取、应用、写提交说明、诊断失败 → LLM。**没有一步是「让模型自己看着办」。**
2. **spec 就是状态机。** 全部进度存在文件里，可编辑、可检查、断点续跑。
3. **失败重算 diff → 自愈。** 每次失败都重新算一次「目标 vs 现状」，让 LLM 顺手捞回漏掉的依赖。
4. **卡住必须有人写 `resolved`。** 不许静默跳过 —— 没人签字说改了什么，循环不继续。这条和我们的 `can_refute` 必填是同一根筋。
5. **WIP 提交留着。** 修复迭代本身是诚实记录，别擦。

**没借的**：它只重构 git 历史，不管「这条历史值不值得留下」。我们多了一句：**一条不能被推翻的判断，不许写。**

## OpenRewrite（openrewrite/rewrite，Java，Apache-2.0）

**一句话**：在大规模代码库上做可重复、可评审的自动重构。

**借的**：

1. **先有「无损」的中间表示，再改写。** LST 不是文本替换，是树；打印回去还保留原格式。→ 我们对应的是**五项结构**：判断先落成「假设 / 证据 / 可能错在哪 / 怎么推翻 / 注释」，不是一段自由文本。
2. **变换是最小侵入的。** 一条 recipe 只干一件事。
3. **recipe 可聚合、可复用。** 同一种「拆判断」的活可以写成配方，不用每次手搓。
4. **改完给 diff，人来评审。** 不是静默生效。

**没借的**：它面向「代码能编译通过」，我们面向「判断能被人改」。**「能过编译」对应「能写推翻条件」** —— 一个可执行的、外部的人能动手的检验。

## Revitalize（James Koppel，C，2012）

**一句话**：程序没有源码了，靠反汇编 + 反编译 + 注释，重建出可维护的源码树。

**借的**：

1. **「理解」就是「重建」。** 它不是把二进制「读懂」了存起来，是把碎片重新组织成有语义的结构。**记忆也一样 —— 不是把话存下来，是每次读重新组织一遍。**
2. **残料也能立骨架。** 反汇编里有大量噪音和丢失信息，它照样先搭骨架，再层层补。→ 对应**补丁式理解**：先接得住方向，字错了也能接。
3. **重建出的东西必须能再编译、再跑。** 重建不是自由发挥，有外部验证。→ 对应**推翻条件**。

**没借的**：它没有「这条重建值不值得留」的判断；我们多一层审美。

## SnapBack（SpaceCypher，TypeScript，MIT）

**一句话**：不依赖 git 提交的项目快照，随时回滚。

**借的**：

1. **内容寻址存储（CAS）。** 文件按 SHA-256 哈希存；相同内容只存一份；快照 = 路径 → 哈希的 manifest。**快照是引用，不是复制。**
2. **快照的意义是「敢试」。** 有便宜的存档，才敢做贵的改写。→ 对应**判断封存**：留一个「现在只是这样」的位置，改起来才没有心理负担。
3. **manifest 即索引。** 不看内容也能列出全部快照。

**没借的**：它恢复的是文件状态，不恢复「为什么当时那么想」。**那道「为什么」我们靠第三、四栏（怎么推翻 / 后来）落。**

---

## 一句话的公约数

> retcon 修历史 · OpenRewrite 修代码 · Revitalize 修无源码 · SnapBack 存状态
>
> **四个都认同一件事：不能证明的东西，不许当成既成事实。**

我们把它缩到一条记忆上：**写下来的判断，必须带一个「什么情况下它是错的」** —— 带不了，就别写。
