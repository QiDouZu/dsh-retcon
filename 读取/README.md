# 读取 · 这个目录里有什么

> 插件装上之后，`封存/` 是空的。**那个空就是位置。**
>
> 这里的文件是**尺子、问题、和两份真事** —— 不是模板让你照抄。

---

## 目录（四个文件，随便挑）

| 文件 | 是什么 | 什么时候看 |
|---|---|---|
| **`标准.md`** | **五项标准**：一条记忆合不合格 + 量表 + **什么时候才配封存** + **衍生规矩** | 想量一条东西之前 |
| **`填空.md`** | 七道题，每道题旁边是**我们的答案**（标着「不是标准」），右边留空 | 想写自己的判据 |
| **`样例一.md`** | 一份**真封存**，它自己只有 4/5 分（栽在假设位） | 想看真事长什么样 |
| **`样例二.md`** | 一次**真批评**（5/10 分），和它逼出来的四处修改 | 想看怎么被推翻 |

**四个可以一起看，也可以只挑一个。**

---

## 阅读顺序（建议，不是规定）

1. **先 `标准.md`** —— 五项，两分钟读完
2. **再 `样例一.md`** —— 看一份 4/5 的真件，然后自己按五项给它打分
3. **然后 `填空.md` 第零节** —— 拿你手上那个冲突写第一条
4. **`样例二.md` 最后看** —— 等你被推翻过一次再看，会更有感觉

---

## 三条守则（填的时候守，不看标准也得守）

1. **「怎么推翻我」写不出可执行的一步 → 别存。** 存了就是信念，信念不该混在判断里过夜。
2. **原片要一起存。** 只存判断，事后补不回它当时的横轴 —— 你连自己当时看见了什么都还原不了。
3. **「后来」空着的，不算知识。** 它只是一个猜想，还挂着。

---

## 还有一件事

**这个目录里没有"标准答案"。**

- `标准.md` 管的是**格式合格**，不管内容对错（它自己在第六节承认了这个漏洞）
- `填空.md` 里空着的题，是**我们也没有**，不是藏着
- 两份样例都是**真的、都不完美** —— 样例一自己只有 4/5 分

**⇒ 你拿它们量自己，也可以拿它们量它们自己。**
